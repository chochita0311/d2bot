# Shared item appearances

| Owner | Role |
| --- | --- |
| `gems/icons/` | The 35 current 32×32 gem templates, named `<quality>-<type>.png`; pixels and quality/type bank order are preserved. |
| `gems/references/` | Seven English quality illustrations retained as an uncalibrated type/quality catalog. They do not replace inventory-matching templates. |
| `gems/amethyst-on-the-ground.png`, `runes/*-on-the-ground.png`, `keys/` | Loot-label appearances, the shared selected key icon and an explicitly retained key illustration. Configured inventory evidence does not establish a completed inventory-confirmation workflow. |
| `runes/icons/` | Generic Jah icon catalog. The separate Ist/Ohm labels remain reusable named-rune examples; only the generic rune label is currently configured for shared loot. |
| `horadric-cube/` | [Selected cube item icon](horadric-cube/README.md); runtime button/hover, panel-negative evidence and the uncalibrated empty-grid catalog belong to [UI](../ui/horadric-cube/README.md). |

Distinct common item types/qualities without maintained replacements remain explicitly cataloged even when no current main consumes them. Catalog images carry no calibrated recognition or action claim. Unnecessary personal bag/equipment layouts and stock sources were removed after useful generic crops were preserved; runtime uses those crops and current observations.
