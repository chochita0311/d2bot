# Character-select marker catalog

`markers/ladder-green.png` and `markers/resurrection.png` preserve the distinct green ladder and gold ruleset-marker appearances. `references/mixed-markers-example.png` shows both together without personal names. These are reusable uncalibrated examples, not an implemented row classifier, character selector or verified mode decision.

Their crop dimensions are known; original viewport geometry and recognition thresholds are not calibrated here. Unnecessary name-bearing character-selection sources were removed; these generic marker crops do not preserve the former complete row geometry or identify a character. [Proposed behavior](../../../docs/features/game-modes.md) keeps the planned classification separate from implemented runtime behavior.
