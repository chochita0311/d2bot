## Goal And Boundary

정책은 캐릭터 설정, 현재 상태는 확인된 관찰/결과가 소유한다. 공통 코드는 캐릭터 이름이나 런에 의존하지 않고 재버프·포션 사용·고갈 종료·보충 필요를 결과로 반환한다.

포함: 선택적 캐릭터 생존 정책과 검증, Flash의 확인값/버프 순서, 방·캐릭터별 버프 시각/벨트 잔량, 중복/오래된 결과 차단, 입력 없는 판단·검증·필드 버프 제한.

제외: 캡처·HUD/벨트 인식기·게임 입력 연결·실제 회복/종료/전투/줍기, GUI 편집기, 자산 이동/이름 변경, 미확정 포션 재사용 간격·전투 모드 해제·관찰 시간 상한의 임의 실게임 기본값.

## Dependencies And Contract Surfaces

기존 JSON 로더만 사용한다. PRD-0008의 실시간 캡처/입력 통합은 이 입력 없는 계약의 선행 조건이 아니며 후속 소비자의 조건이다. 미확정 실게임 인식·시간·키 동작은 이번 기능의 통과 주장에 포함하지 않는다.

생산자는 실제 시전/종류/획득/소모의 정답과 같은 monotonic 시계의 관찰 시각, 방·캐릭터 ID, 증가하는 sequence를 제공한다. 소비자는 최신 관찰과 명시적 시간 상한으로 판단을 요청하며 반환값을 실제 입력/완료 증거로 취급하지 않는다. 보충 필요 결과는 전투 모드 해제 기준이 아니다.

140/150초·다른 지속시간·중단/실패 시전, 50%/10%와 7/6/1/0개, 미관찰·잘못된 종류·중복·순서 역전·수동 변경·방/캐릭터 전환을 입력 없이 검증한다. 기존 마을 회귀와 설정 선택을 유지하고 변경 Python의 compile/Black 검사를 수행한다.
