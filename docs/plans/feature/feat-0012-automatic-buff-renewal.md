# FEAT-0012: 필드 실행 루프의 자동 버프 갱신

- ID: `feat-0012`; Status: `approved`; Type: `product`
- Parent: [PRD-0004](../prd/prd-0004-summoner-survival-and-buffs.md)
- Profile: `backend-product`; Evaluators: Contract, Functional
- Created: `2026-10-09`; Updated: `2026-10-11`
- Approval: 사용자가 기계적으로 확인하는 동작을 프로그램으로 미리 연결하고, 타이머와 현재 주변 안전 조건으로 자동 재버프하도록 지시했다. 기존 전체 구현·감독 검증 승인을 유지한다.

## Goal And Acceptance

최신 GUI/main 통합 상태는 [통합 run Attempt15](../run/run-20261009-07-summoner-live-integration.md#attempt15-세션-마감-정리와-다음-gui-실행-인계)가 소유한다. 사용자의 후속 지시에 따라 감독 JSON/I 없이 현재 근접 후보·비율 안정으로 전체 순서를 보내고 실제 S 요청+140초에 갱신하도록 연결했다. 정상 main의 전송은 `dispatched_unconfirmed`, 전체 효과는 `not_independently_verified`이며 제때140초 실게임 갱신은 아직 미검증이다. 아래 AB 계약과 전용 run은 최초 공통 확인 경계의 수용 조건·증거로 보존하며 최신 main이 독립 효과 확인까지 통과했다는 뜻이 아니다.

140초 갱신 시점에 사람이 도구 입력을 맞출 필요가 없도록 공통 필드 runtime이 버프 요청을 직접 소비한다. 기존 캐릭터 정책·순서·간격과 시각 확인 계약을 재사용하고, 비전/기록 대기 때문에 watchdog을 막는 연속 sleep을 추가하지 않는다.

| ID | 수용 조건 |
| --- | --- |
| AB-01 | 같은 단조 시계의 확인된 시전 시각에서 갱신하며, 갱신 필요 시 이동/공격을 해제하고 최신 안전 관찰에서 자동 순서를 시작한다. |
| AB-02 | 각 키와 키 사이에도 현재 HUD·필드·주변 안전·벨트·포커스·중단을 확인한다. 불명확/위험/시간 초과는 추가 버프를 취소하고 사람 검토를 요구한다. |
| AB-03 | 키 간격 대기는 비차단 상태로 진행하고, 관찰 중단·pause·stop·예외에도 키가 남지 않는다. 실패 뒤 자동 재시작하지 않는다. |
| AB-04 | 전송과 효과/장비 복귀를 분리한다. 같은 새 프레임의 검증된 확인만 타이머를 갱신하고, 확인 지연으로 유효 시간을 늘리지 않는다. |
| AB-05 | 가짜 시계/입력으로 최초·140초·반복·지연·적 접근·관찰 끊김·확인 실패를 검증한다. 실제 자동 안전 생산자와 감독 140초 시험은 별도 증거이며 미검증을 통과로 기록하지 않는다. |

몬스터 후보의 미검출은 전체 적 부재 확정이 아니다. 최초 공통 경계에서는 자동 안전/전체 효과 생산자의 검증이나 감독 연결 전 기존 GUI의 장시간 live 활성화를 제한했다. 이후 승인된 최신 main은 위 자동 안전 관찰과 전송 기반 시한을 사용하며 독립 효과 확인의 미완료를 그대로 기록한다. 회복/탈출 요청과 실제 완료도 구분한다.

2026-10-10 사용자가 버프 안전을 **근접 적 없음 + 생명력·마나 비율 안정**으로 확정했다. 먼 원거리 적의 가시성만으로 버프를 막지 않는다. 당시 개발 경로는 최신 감독 근접 확인과 매 키 전 HUD·근접 양성 후보 검사를 연결했고2026-10-11 정상 main에서 감독 JSON 요구를 제거했다. 초기1초의 비율 관찰과 최근1초의 확인된5퍼센트포인트 급락을 개발 기준으로 검사하며 구체 하한은 구간으로 보존한다. 제한된 근접 후보 미검출을 자동 전체 clear/효과 생산자나140초 갱신 통과로 확대하지 않는다.
