후속 Attempt14(2026-10-11)은 사용자 재요청으로 assets 전체 구조·파일명과 불필요한 이미지까지 정리했다. 공용339/private23개로 유지하고 코드·설정·테스트·현재 문서 참조를 갱신했다. 전체558개 입력 없는 회귀가 통과했으며 실제 게임 수용은 추가하지 않았다. 구조/보존 기준은 [assets 안내](../../../assets/README.md), 상세 증거는 [통합 run Attempt14](../run/run-20261009-07-summoner-live-integration.md#attempt14-assets-전체-구조와-불필요한-이미지-정리)가 소유한다.

GUI 통합 상태(2026-10-11, Attempt13): 예전 북쪽 실행기/버튼을 제거하고 최신 main을 GUI에 연결했다. 선택 캐릭터·난이도·1–5회와 중단을 전달하며, 감독 JSON/인벤토리 I 없이 현재 근접 후보·생명력/마나 비율로 버프를 준비하고 실제 S 요청+140초 갱신을 연결했다. ALT는 이동 OFF→실제 노바 종료 후 ON 검사→OFF로 변경했다. 공용 지형/UI/클래스/카메라 자산을 private에서 분리하고 개인 창고 의존도 제거했다. 전체557개 입력 없는 검사가 통과했으며 GUI 생성/최소 배치도 검사했다. 실제 화면 확인 중 아래 버튼 잘림을 수정했으나 두 번째 Computer Use 확인은 사용자의 물리 Escape로 중단됐다. 게임 입력은 보내지 않았다. 수정 후 자동140초 갱신·조건부ALT·새 방 완전 왕복0/5·실제 서모너 처치/열쇠 획득·네 방향·30방 수용0방은 미검증/미완료다. [최신 통합 run](../run/run-20261009-07-summoner-live-integration.md)이 실제 증거와 다음 작업을 소유한다.

직전 실제 검증 이력(실행222까지): 잠금 해제 뒤218의 새 방 북쪽 계단→서모너 발판 이동을 관찰했고, 룬 모양과 자리의 결합을 수정한219는 첫 탐색 화면에서 현재5개 룬으로 목표를 선점했다. 전용 접근/노바는0회·kill_unconfirmed다.220의 감독 개발 복귀는 중앙 근접·정지→Act1→종료→새 방 진입을 자동 연결했다. 초기 복귀는 완료 수에서 제외한다. 새 방01은 북쪽 세 상자 끝까지 도달했지만 이동 후 접근 추적의 정지 전환을 놓쳤고,221은 겹친 이름표 때문에 현재 두 부위 확인이 끊겨 끝 도착을 보류했다. FEAT-0013/SPEC-0012 Attempt12에서 이름표 행 분리와 이동 후 두 부위의 정지 전환을 보완했다. 전투 접근 거부 원인 기록도 추가했고 최신 전체508개 회귀·변경 파일 Black/컴파일·diff check가 통과했다.222는 입력 전에 창 활성화가 실패했고 새 캡처도 검어 화면 복구를 기다린다. 수정 후 실제 끝 도착은 아직 미확인이다. 현재 비율 기반 비상 포션 소비도 공통 연결했지만 실제 회복 소비는 미확인이다.208 감독 갱신의17.969초 지연은 제때 자동 갱신 통과가 아니며210 보고서는 저장 중 중단으로 없어 저장 화면만 사용한다. 새 방 완전 왕복0/5·30방 수용0방, 실제 처치/회수·제때 자동140초 갱신·네 방향은 미완료다. 아래 과거 실행 상태는 당시 이력이며 상세 증거는 통합 run이 소유한다.

단일 통로→직사각형 갈림→합류→종착이라는 관찰을 지도 이해의 참고로 사용한다. 해당 순서나 좌표를 모든 지도의 정답으로 강제하지 않는다. 현재 보이는 발판의 연결과 굴곡, 이동 전후 배경 대응, 긍정적인 끝/중앙 증거로 이동한다. 서모너 발견 뒤 남은 날개를 생략하는 기존 요구는 유지한다.

아케인의 상자·관·신단·맵 텔레포터 호버는 이동 입력 충돌 대상이다. NPC 호버는 사용자의 정정대로 마을에만 적용한다. 늦은 프레임·텔레포트 전 조준점·관찰 없는 고정 홀드를 다음 입력에 재사용하지 않는다. 기존 팔레트/템플릿은 후보 자료이며 그래픽·크기·현재 장면 적합성을 검증한다.

현재 증거(2026-10-10): main122는 세 상자 끝을 자동 확인하고 같은 방 중앙 복귀를 시작했다.124는 추가 시전 완료 뒤 중앙에서 멀어져 안정 도착을 승인하지 않았고,125는 중앙 오인식·마나 고갈 뒤 안전 종료했다.127/139는 호라존 일지·룬 발판까지 이동했으며 현재 목표 판독기는 기존 일지 자산을 재검증해 사용한다. 기존 방의 서모너는 이미 처치됐다는 사용자 확인이 있으므로 새 처치 실적이 아니다.129 이후 텔레포터 구간과 중앙 통과 실패를 보완했고,137은 실제 중앙 근접·정지에 성공했다.141은 중앙 인식 뒤 기존 조준으로 남쪽 끝까지 지나쳤다. 목표 선점 수정 후144는 기존 방 중앙 복귀→Act 1→방 종료→새 방 성역 진입을 자동 수행했다. main152는 현재 세 부위와 안정 정지로 끝을 승인했으나 복귀에서 약한 몸 후보 오보정으로 실패했다.154의 작은 상자 세 개 변형은 기존 공용 외형을 재조합해 보완했다.156은 실제 중앙까지 왔지만 문양 가림으로 자동 승인을 보류했고,157은 중앙 도착→Act 1→새 방 진입을 다시 자동 수행했다. 검토 카메라 지속 투영과 정적 끝/중앙 추적을 연결했다. 이후160의 이름표 가림을 보완했고 이름표 항상 ON을 공통 기본으로 확정했다.165의 호버 조준 반복을 줄인166/167은 실제 F2 전송0회였으며, 입력 없는 정체를 길 막힘으로 잘못 분류하던 결함을 수정했다. 전체443개 검증 뒤 마지막 입력 보완의 관련109개 테스트가 통과했다.168은 검은 화면/창 활성화 실패로 입력0회였으므로 수정 후 실게임 이동은 화면 복구를 기다린다. 코드 검증과 새 방 북쪽 왕복 성공을 구분한다. 현재 우선순위는 북쪽 끝→중앙 WP→Act 1→새 방→북쪽의 반복이며 동/남/서는 이후 연결한다. 실제 처치/회수·140초 자동 갱신·북쪽 새 방 반복·네 방향·30방 수용은 미완료(수용0방). [현재 run](../run/run-20261009-07-summoner-live-integration.md#attempt8-북쪽-도달과-새-방-단위-반복-연결)이 상세 실행 증거를 소유한다.

사용자는 같은 날개도 방마다 바닥 타일과 굴곡에 variation이 있고 계단형·텔레포터형 등의 유형이 있음을 재확인했다. 유형 자산은 현재 화면 해석의 보조 근거이며 특정 방의 좌표나 한 장의 타일을 전체 경로로 강제하지 않는다. 타일 색·외형 일치와 실제 착지/이동·출구 확인을 분리한다.

지도 참조는 후속 설계 후보로 기록한다. 사용자가 알려준 현재 투명도47은 고정 규칙이 아니며 투명도·크기·위치 변화에도 지도 자체를 인식·재추적해야 한다. 현재 ON 준비의 지역명 확인과 무채색 간섭 보정은 일반 지도 인식/길 해석 기능이 아니다. [지도 관찰 조건](../spec/spec-0012-arcane-perceptual-navigation.md#contract)에 표시 변화·지도/화면 대응·추적 비용·근거 미확인 시 입력 경계를 기록했다. 지금은 중앙 복귀 보정과 main 검증을 우선한다.
