# FEAT-0014: 서모너 발판 접근과 전투 전후 증거

- ID: `feat-0014`; Status: `approved`; Type: `product`
- Parent: [PRD-0006](../prd/prd-0006-summoner-combat-and-loot.md)
- Profile: `backend-product`; Evaluators: Contract, Functional
- Created / Updated: `2026-10-10`
- Approval: 사용자는 요구사항 확정·구현·감독 검증을 끝까지 진행하고 북쪽 끝에서 서모너가 있으면 처치·열쇠 확인 뒤 중앙으로 복귀하도록 승인했다. 미검출을 사망으로 바꾸지 않는 기존 요구는 유지한다.

## Goal And Acceptance

현재 서모너 발판을 찾았지만 로브가 가려졌다는 이유로 가장자리에 멈추는 문제를 해결한다. 현재 서로 다른4개 이상 룬과 검토 여섯 자리의 일대일 정합 또는 일지와 룬으로 목표 바닥을 구하고, 실제 바닥 지지를 확인한 제한된 접근 뒤 현재 근접 적의 긍정 근거로 노바를 실행한다. 전투 전후의 신원·사망·드롭 검토에 필요한 화면을 제한된 버퍼에 보존한다.

- 현재 목표 발판·HUD 비율·발 위치·포커스·버프 시한과250ms 화면을 요구한다. 목표 위치는 현재 랜드마크의 이동으로 구하며 과거 커서 좌표를 재생하지 않는다.
- 최대2회 접근·전체12초·노바6초 상한을 유지한다. 공격 OFF에서는 접근/공격을 연결하지 않는다.
- 전투에는 기존 로브 후보 또는 실제 커서와 후속 현재 붉은 적 패널을 요구한다. 목표 발판만으로 적·신원·처치를 선언하지 않는다.
- 최대4개 사전 프레임과24개 전투/후속 프레임만 보존한다. 기록 시각/현재 후보·패널·실제 입력을 연결한다. 미검출이나 드롭만으로 처치를 확정하지 않는다.

## Boundary And Verification

이번 경계는 접근·전투 증거 생산이다. 실제 서모너 신원/사망 연결, 승인 전리품 획득, 정상 복귀와5/30방 수용은 후속 통합에서 별도로 검증한다. 기존 방 종료/새 방 생성은 미확인 처치/회수 뒤 실행하지 않는다. 공용 바닥 위치·판독은 region owner, 전체 개인 화면은 private owner에 둔다.

입력 없는 검증은 바닥/후보 누락·오래된 화면·자원 부족·시한·중단·전투 OFF와 기록 상한을 다룬다. 실제 main은 현재 발판 접근과 적 패널→노바의 소비를 확인하며, 죽음 자료가 없으면 결과는 kill_unconfirmed다.
