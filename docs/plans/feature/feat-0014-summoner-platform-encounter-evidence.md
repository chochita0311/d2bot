- Profile: `backend-product`; Evaluators: Contract, Functional

- Approval: 사용자는 요구사항 확정·구현·감독 검증을 끝까지 진행하도록 승인했다. 2026-10-11 처치·열쇠 확인 뒤 일지→즉시 가까운 바닥 클릭→붉은 포탈→협곡WP→Act 1→방 종료로 변경했고 필드 아이템은 텔레포트 한 번 뒤 클릭하도록 정했다. 이전 처치 후 중앙 복귀를 대체하며 미검출을 사망으로 바꾸지 않는 요구는 유지한다.
- 2026-10-18 정정: 주변 몹 대상 노바에 서모너가 함께 죽을 수 있다. 개별 서모너 타겟팅·강제 F2·그 뒤 생존 재확인을 필수로 두지 않는다. 발판 인식과 별도로 생존/시체 외형 인식을 개선하며, 현재 발판의 검토된 시체를 확인하면 전리품·협곡 마감으로 잇는다.

## Goal And Acceptance

현재 서모너 발판을 찾았지만 로브가 가려졌다는 이유로 가장자리에 멈추는 문제를 해결한다. 현재 서로 다른4개 이상 룬과 검토 여섯 자리의 일대일 정합 또는 일지와 룬으로 목표 바닥을 구하고, 실제 바닥 지지를 확인한 제한된 접근 뒤 현재 근접 적의 긍정 근거로 노바를 실행한다. 전투 전후의 신원·사망·드롭 검토에 필요한 화면을 제한된 버퍼에 보존한다.

- 현재 목표 발판·HUD 비율·발 위치·포커스·버프 시한과250ms 화면을 요구한다. 목표 위치는 현재 랜드마크의 이동으로 구하며 과거 커서 좌표를 재생하지 않는다.
- 최대2회 접근·전체12초·노바6초 상한을 유지한다. 공격 OFF에서는 접근/공격을 연결하지 않는다.
- 전투에는 기존 로브 후보 또는 실제 커서와 후속 현재 붉은 적 패널을 요구한다. 목표 발판만으로 적·신원·처치를 선언하지 않는다.
- 최대4개 사전 프레임과24개 전투/후속 프레임만 보존한다. 기록 시각/현재 후보·패널·실제 입력을 연결한다. 미검출이나 드롭만으로 처치를 확정하지 않는다.

## Boundary And Verification

녹색 효과에 가린 접힌 시체는 별도 하단 주름 native .92로 보완하고 원래 외형 .90을 유지한다. 축소 검색이 두 번째 몸체만 놓치는 회귀를 근거로, native RGB를 이미 통과한 부위에 한해서 같은 원본/임계값으로 유일성을 추가 검사한다. 새 후보 승인·시체 연결·입력 허가는 만들지 않으며 상세 경계/실행 결과는 SPEC-0013/통합 run이 소유한다.

이번 실행에서 새 발판을 실제 확인한 뒤 전투 가림으로 잃으면 현재 발/화면을 유지하며 최대6초 재획득한다. 방어 호버는 현재 녹색 근접 후보를 우선 사용하며 없으면 기존 현재 발 기준의 제한 격자를 사용한다. 실제 커서·현재 근접 위치·새 적 패널을 모두 요구하며 과거 발판으로 이동/처치를 승인하지 않는다. 발/화면 소실·발판 미확인의 기존1초 중단과 노바6초/전체12초·버프 시한은 유지한다. 새 방31 후속 감시의 접힌 파랑/금색 시체 로브는 같은 검토 종류이며 같은 방의 조명 양성/음성 근거로 해당 외형만 native RGB .92→.90으로 조정했다. 앞선 전투 양성/처치를 뜻하지 않으며 새 현재 발판·두 시체 화면/유일성은 계속 필요하다. 정확한 조건은 SPEC-0013이 소유한다.

2026-10-20 일지 가림 보완은 같은 현재 안전 바닥 중 책 옆 목표를 가까운 쪽부터 확인하고 수평120px 이상·책220px 이내인 곳으로만 접근한다. 정확한 목표/오차·최대2회·새 일지/발/HUD·시한은 SPEC-0013이 소유한다. 입력 없는 회귀와 실제 일지/협곡 마감 결과는 통합 run의 개발 재개에서 구분한다.

현재 외형의 후보 생성만 반해상도 회색조로 줄이고 native RGB 승인/유일성/새 시체 쌍 계약은 보존한다. 옆 주름 생존 로브와 굽은 시체 옷자락은 별도 .92 외형이며, 협곡 계단은 실제 양성/음성을 근거로 기존 외형만 .90으로 보완했다. 새 방18 실패와 같은 방의 시체 쌍·전리품 검사·일지/협곡/Act1 복구 완료를 구분하며 열쇠 획득은 미확인이다. 상세 수치/조건은 SPEC-0013과 통합 run이 소유한다.

이번 경계는 접근·전투 증거 생산이다. 실제 서모너 신원/사망 연결, 승인 전리품 획득, 정상 복귀와5/30방 수용은 후속 통합에서 별도로 검증한다. 기존 방 종료/새 방 생성은 미확인 처치/회수 뒤 실행하지 않는다. 공용 바닥 위치·판독은 region owner, 전체 개인 화면은 private owner에 둔다.

입력 없는 검증은 바닥/후보 누락·오래된 화면·자원 부족·시한·중단·전투 OFF와 기록 상한을 다룬다. 2026-10-11 사용자가 같은 방의 파랑/금색 생존 로브와 가로 시체를 확인했다. 최신 정정에 따라 같은 방·이동 세대·현재 발판 상대 위치의 두 순서 있는 현재 시체 관찰을 요구하되 생존 관찰은 선택 증거로 둔다. 일반 전투와 전용 인식 단계의 경계가 처치 인정 여부를 가르지 않는다. 실제 main의 자동 처치/획득과 협곡 마감은 별도 실게임 검증이며 시체 쌍 미확인·미검출은 kill_unconfirmed다.
