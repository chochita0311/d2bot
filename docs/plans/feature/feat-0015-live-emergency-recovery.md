# FEAT-0015: 실제 main의 비상 포션 회복

사용자가33번 이후 수동 복구와 재시험을 알리며 생존을 첫 규칙으로 명시했다. 현재 알려진 저자원은 다른 숫자의 가림보다 먼저 처리하고 전리품/ALT 복원에도 공통 회복을 연결한다. 닫힌 벨트/포션 외형과 새 두 비율·잔량·닫힘 전제는 유지하며, 회복 실패/같은 검사 중 재발·6초 미해결 현재 근접 위협은 안전 종료한다. 임계값을 새로 정하거나 자동 부활/보급을 추가하지 않는다.

- ID: `feat-0015`; Status: `approved`; Type: `product`
- Parent: [PRD-0004](../prd/prd-0004-summoner-survival-and-buffs.md)
- Approval: 사용자가 비율 기반 비상 회복과 구현·감독 검증을 승인했다. 새 운영 수치를 정하지 않고 확정된 생명력50%/마나10% 미만과 보라 포션 열을 사용한다.
- Profile: `backend-product`; Evaluators: Contract, Functional; Created: `2026-10-10`

main216은 대기 중 마나 비율 .0279에서 포션 입력 없이 안전 종료했다. 이동/전투/대기에서 현재 자원 부족을 발견하면 유지 키를 해제하고 현재 닫힌 벨트의 보라 포션을 확인한 열만1회 사용한다. 새 HUD 회복과 펼친 벨트의 실제 잔량·닫힘을 확인한 뒤 기존 동작으로 돌아간다. 키 전송을 사용/잔량 감소로 확정하지 않으며 실패·고갈은 기존 안전 종료로 보낸다.

다른 런/캐릭터도 같은 recovery consumer와 개인 정책을 사용할 수 있다. 자동 줍기/재보급/사망 복구와 전체 런 수용은 이번 경계에 포함하지 않는다. [SPEC-0014](../spec/spec-0014-live-emergency-recovery.md)와 통합 run이 결과를 소유한다.

2026-10-20 재개33번은 첫 포션 요청 뒤 새 HUD 회복·펼친 실제 잔량·닫힘을 확인했지만 두 번째 요청은 회복 뒤 빈 아래 칸 분리 실패로 잔량/닫힘을 승인하지 못했고 안전 종료도 미확인이었다. 실행 직후 감독 화면에서 실제 사망을 확인했으므로 전체 생존/안전 종료 수용은 실패다. 빈 칸 외형, 기존 저자원 기준의 벨트 대기 선점, 현재 관측으로 닫기와 field backend 종료/진단을 보완했다. 이는 입력 없는 검사로 확인한 수정이며 수정 후 실게임 사망 예방을 입증하지 않는다. 최신 실행별 결과·수동 복구 대기·검증은 [통합 run Attempt18 개발 재개](../run/run-20261009-07-summoner-live-integration.md#development-resume-20261020)가 소유한다.
