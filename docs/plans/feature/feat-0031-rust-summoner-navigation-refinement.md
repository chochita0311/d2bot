## Goal And Authority

사용자가 Rust 포팅 검증 뒤 기존 서모너 개발 재개, 성공/실패 합계3회마다 검토·최적화, 더 가까운 일반 위협만 공격, 굴곡의 왕복 감소와 필요시 맵 유형별 공통 자산 보완을 승인했다. 기존 북쪽 단독10연속→같은 방 북남10회→동쪽 단독→북동남→북동남서 순서를 유지한다. 포팅 시험과 복구는 개발 성공에 더하지 않는다. 현재 단계A의 연속 성공은0이며 새 Rust 묶음을 별도 번호로 기록한다.

## Scope And Acceptance

일반 이동의 공격/호버 반경을 공용 run 설정으로 좁히고 같은 값으로 관측 후보·실제 호버 확인·현재 근접 전투를 연결한다. 서모너 전용 전투와 정지 중 방어·비상 회복은 기존 범위를 유지한다. 현재 바닥에 근거한 굴곡 연속성과 위치 대응을 잃었을 때의 경로 선택을 보완한다. 실제 이동과 단순 조준 변경을 구분하고3회마다 Nova 비중/반전·재방문/정체/목표 재획득·종료와 비용을 확인한다.

2026-10-30 사용자가 R18 녹화 병행 실제 입력 시험을 명시 승인하고, 룬은 이스트 이상만·보석은 수집하지 않도록 변경했다. 현재 이름 자산은 이스트/오움 두 종뿐이므로 공통 룬·보석 후보를 제외하고 이 두 이름만 제한적으로 수집한다. 나머지 대상 룬의 자산/판독·검증과 전체 등급 선별은 미완료로 남기며, 이름 미확인을 허용 품목으로 추정하지 않는다. 증오의 열쇠와 기존 조건부 접근·클릭·미확인 획득 의미는 유지한다.

사용자는 서모너 처치 후 반복 훑기 대신 지도 가림 해소·빠른 처치 판독과 정상 포탈 마감을 요청했다. 정상 목적지는 일지→붉은 포탈→협곡 WP→Act1이며 중앙 복귀로 바꾸지 않는다. 처치/열쇠 미확인을 중앙 복귀로 보내려던 작업 분기는 사용자 정정에 따라 제거했다. 대기 방어 중에도 현재 시체 후보를 확인하면 한 번 정식 처치 판독으로 돌아가고, 긍정 처치·전리품 검사 뒤 원래 협곡 경로를 실행한다. 미검출을 죽음으로 바꾸지 않는다. 별도 요청한 GUI 로그는 바닥 따라가기/위로 읽기 유지/바닥 복귀 시 따라가기 재개를 적용한다.

새 유형 자산은 현재 장면의 근거를 얻은 경우에만 기존 region owner로 일반화한다. 특정 방 좌표/전체 경로를 강제하지 않고 계단·텔레포터/비텔레포터·굴곡을 현재 연결/안전 바닥으로 확인한다. 자산과 판독이 불필요하면 추가하지 않는다.50ms는 지향 목표이며 기능/정확도/안전을 낮춰 숫자만 맞추지 않는다.
