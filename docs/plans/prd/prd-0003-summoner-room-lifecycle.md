## Request Summary

로그인 후 캐릭터 선택 화면에서 출발하여 방을 생성하고, 한 번의 서모너 런이 끝나면 Act 1에서 마감한 뒤 캐릭터 선택 화면으로 돌아오는 반복 경계를 정의한다. 최우선 검증 대상은 방 생성·종료이며, 장시간 반복은 단계별 감독 검증 이후의 결과다.

## Product Intent

사용자가 현재 상태와 다음 행동을 이해하고 언제든 개입할 수 있는 방 반복을 제공한다. 방 생성 버튼을 눌렀다는 사실과 플레이 가능한 방에 들어갔다는 사실, 종료 버튼을 눌렀다는 사실과 캐릭터 선택으로 돌아왔다는 사실을 구분한다.

## Confirmed Scope

- 이미 로그인한 온라인 소프트코어 기본 Resurrection의 원소술사 Flash를 대상으로 선택 캐릭터·게임 모드·난이도를 확인한다. 초기 범위는 사람이 게임에서 캐릭터를 선택하고 프로그램 프로필과 일치함을 확인하는 방식도 허용한다.
- 캐릭터 선택, 방 생성/난이도 선택, 로딩, 플레이 가능 마을, 종료 메뉴, 캐릭터 선택 복귀를 화면 증거로 구분한다. 온라인 로비의 별도 생성 흐름은 대상 모드 확인 후 경계를 정한다.
- 정상 종료는 Act 1의 안전한 마감 상태를 확인한 뒤 수행한다. Act 2 마을에서 방을 끝내는 것을 정상 성공으로 세지 않는다.
- 한 방의 런 결과를 정확히 한 번 기록하고, 종료 확인 전에는 다음 방을 만들지 않는다.
- 시작 상태가 불명확하거나 이미 게임 중이면 무조건 새 방을 만들지 않고 상태를 알린다. 승인된 재개 경계만 사용한다.
- 창 이동·크기 변경·포커스 상실·캡처 실패·로딩 지연·연결 오류·잘못 열린 메뉴에 대해 입력 억제와 제한된 복구를 요구한다.
- 모든 실제 입력 경로에 관찰 전용, 일시정지, 즉시 중단, 수동 개입 우선권을 요구한다. 대기 중인 입력과 눌린 키도 취소/해제되어야 한다.
- 반복 횟수·총 시간·연속 실패의 상한을 사람이 확인한다. 빈 입력을 무한 반복 승인으로 해석하지 않는다.

## Excluded Scope

- 로그인 자동화, 계정 정보 저장/전송, 게임 실행·업데이트.
- 캐릭터 목록 전체 OCR 및 자동 캐릭터 전환, 타인의 공개 방 참가.
- 이 PRD에서 생존 수치·전투·아이템·네 방향 이동을 구현하는 것. 각 내용은 별도 PRD 소유다.
- 승인된 마을 반복 증분 밖의 완전 런 코드 수정·실행. 제한 증분의 구현·감독 테스트는 아래 승인 경계를 따른다.
- Act 1 정상 마감 조건을 비상 탈출에도 강제하는 것. 위험 시에는 생존 요구가 우선한다.

## Constraints

- 화면 캡처, OpenCV/OCR, 일반 Windows 입력만 사용한다. 내부 상태 접근 금지는 [프로젝트 정책](../../project/policy.md)을 따른다.
- 현재 GUI 동작의 `dry_run` 및 단축키 적용 범위가 불완전하다. 설정에 값이 있다는 이유로 감독 안전성이 확보됐다고 취급하지 않는다.
- 상태 변경은 최신 화면의 긍정 증거가 필요하다. 버튼 클릭이나 고정 대기시간만으로 성공을 선언하지 않는다.
- 안전 동작이 미검증된 상태에서 전투 지역의 방 반복을 승인하지 않는다. 먼저 마을 범위의 반복만 검토한다.
- `2026-10-04` 후속 요청으로 방 생성→Act 2→Act 1→종료→재생성의 감독 마을 증분과 필요한 구현·캡처를 승인받았다. [FEAT-0002](../feature/feat-0002-supervised-town-room-loop.md)가 해당 경계를 소유한다. 장시간 무감독 반복, 전투·생존 통합 및 전체 공통 안전 기능의 수용은 승인되지 않았다.

| ROOM-05 | 실험별 횟수·시간·실패 상한과 입력 중단 지연이 측정·승인됨 | [실험 계획](../../features/summoner-experiment-plan.md)의 E1 검토 |

표본 목표는 실험 계획의 초안 제안이다. 성공 사례만 골라 완료를 주장할 수 없으며, 오류 사례가 없는 경우 오류 대응의 검증 범위도 미확인으로 남긴다.

## Candidate Features

- Foundation 후보: 선택/로딩/마을/종료 상태와 입력 권한의 관찰 계약.
- Product 후보: 선택 화면에서 마을까지의 생성 결과 확인.
- Product 후보: 마을에서 종료하고 선택 화면으로 복귀하는 결과 확인.
- Product 후보: 횟수 제한과 사람이 중단할 수 있는 마을 반복.

후보는 기능 문서나 실행 승인으로 간주하지 않는다. 생존과 복귀 의존성이 준비된 뒤 완전 런의 반복 연결은 [PRD-0006](prd-0006-summoner-combat-and-loot.md)에서 승인한다.
