## Attempt3: main 통합 실행과 현재 수정

사용자는 마우스·키보드를 프로그램에 맡겨 검증하도록 승인했다. 실제 `main.py --summoner-run --live`는 방 진입→무기 세트 I 확인/필요 시 복귀→`w,a,a,s,d,f1,w` 전체 시퀀스→감독 효과 확인→북쪽1–12회(기본3회) 제한 이동을 한 프로세스에서 수행한다. 매 키별 Computer Use 조작을 실행 경로로 사용하지 않는다. 이 CLI는 개발 중의 제한 구간이며 방 완주가 아니다. 기존 GUI에 전체 탐색 실행을 연결하지 않았고, 30방 수용은 **0방**이다.
