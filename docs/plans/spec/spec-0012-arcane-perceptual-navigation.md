도착에는 충분한 누적 이동과 참고 하한 외에 `SearchLimits.settled_frames`개 이상의 연속 안정 화면이 필요하다. `settled_frames`는2 이상 정수, `settled_motion_pixels`는 프레임 간 검증한 배경 이동 길이의 양수 상한(px)이다. 큰 추가 이동/배경 대응 미확인은 안정 횟수를 초기화하고 도착 시한은 연장하지 않는다. 합성 검증의2프레임/2px를 실게임 운영값으로 추정하지 않는다.

호버 해소는 move-only 요청 뒤 새 프레임에서 호버 없음이 확인돼야 cast를 허용한다. 회피 횟수/도착/날개/귀환/전체 상한은 명시적으로 소비하며 같은 좌표 반복으로 늘리지 않는다. 매 요청의 실제 입력 adapter는 최신 HUD/버프/포커스/중단과 창 경계를 다시 검사한다. 생존 조건이 불명확하면 요청을 전송하지 않는다.

긍정적 nonboss_end→return_hub→긍정적 hub_ready→다음 날개 순서를 강제한다. summoner_present는 남은 날개를 취소하고 상위 전투/회수에 인계한다. 네 날개 모두 빈 끝이면 탐색 이상이다. 일반 종착 후보나 보스 미검출을 nonboss_end로 바꾸지 않는다. 중단/실패는 재시작하지 않는다. 실제 observer/입력 실행 경로와 기존 GUI 연결은 필요한 관찰이 준비된 범위에서만 활성화한다.

Attempt12는 이동 후 접근 추적에도 기존 재정합과 같은 정지 전환을 적용한다. 최초 전체 배치의 원래2초 안에서 직전과 현재의 동일 두 부위 이상을 native .92·기존 가시 텍스처60% 이상으로 재확인하고, 각 위치 변화와 별도 현재 배경 이동이 모두2px 미만이면 `current_motion_settled_two_parts`를 도착 대기에 제공한다. 한 부위·배경 미확인·큰 이동·원래 시한 초과는 승격하지 않는다.400px 근접·최소0.6초/두 정지 화면·최종 현재 판독은 유지한다.

겹친 이름표가 세로 확장 단계에서31px 초과 성분으로 합쳐지면, 확장 전의 독립 성분을 같은 원래 크기·밝기·어두운 배경 조건으로 재검사한다. 큰 덩어리 전체를 가림으로 승인하지 않는다. 현재 가시 텍스처60%·native .92·현재 두 부위와 원래2초 시한은 유지한다.221의 마지막 화면은 북서쪽/작은 상자 두 부위만 확인하며 남동쪽 점수는 미확인으로 남긴다.
