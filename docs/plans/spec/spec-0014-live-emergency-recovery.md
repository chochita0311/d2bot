# SPEC-0014: 비상 회복 입력과 실제 잔량 재판독

- ID: `spec-0014`; Status: `ready`; Feature: [FEAT-0015](../feature/feat-0015-live-emergency-recovery.md)
- Run: `run-20261009-07`; Attempt: `18`; Profile: `backend-product`; Evaluators: Contract, Functional

Flash 새 방의 현재 용병 얼굴 미확인도 `mercenary_unverified`로 기존 즉시 안전 종료에 전달한다. 이동/공격을 해제한 뒤 내부 stop을 세워 종료까지 막거나 필드에 감독 대기로 남기지 않는다. 현재 포커스·사용자 중단 없음과 아래 현재 메뉴/실제 커서/새 화면/선택 확인을 그대로 요구하며, 사용자 중단/포커스 상실에는 종료 입력도 금지한다. 감독 검토 표시는 유지하고 NPC/부활/다음 방을 추가하지 않는다. 얼굴 부재·미확인은 사망 판정이 아니며 같은 화면의 알려진 저자원은 계속 우선한다. 현재 얼굴 기준은 survival manifest의 단일 template .92/라벨 가시50%이며 보정·실제 실패/사망 상태의 한계는 통합 run이 소유한다.

자원 부족은 같은 현재 HUD의 각 자원 현재값/최대값 비율로 판단한다.250ms 이내·포커스·중단·닫힌 벨트와 현재 보라 포션 외형이 확인된 개인 정책 열만 선택한다. TP 열/미확인 칸에는 입력하지 않는다. F2/F4를 먼저 해제하고 포션 키는 한 시도당1회만 전송한다.

현재 알려진 한 비율이 생명력50%/마나10% 미만이면 다른 숫자나 벨트가 미확인이어도 resource_low를 먼저 전달한다. 이는 포션 입력 허가가 아니며 consumer는 현재 닫힌 벨트·보이는 포션을 별도로 요구한다. 부족했던 알려진 비율의 상승과 두 새 비율 모두의 임계값 충족 없이 복귀하지 않는다. 처음 미확인인 자원의 이전 값은 만들지 않는다.

새 HUD에서 낮았던 비율의 상승과 두 회복 임계값 충족을1초 안에 확인한다. 그 뒤 벨트를 펼쳐 실제16칸을 읽고 닫힌 상태를 별도로 확인한다. 전체 시도는3초·방당 최대12시도로 제한한다. 잔량은 펼친 현재 벨트에서만 갱신하며 단순 전송/색 변화/자연 회복을 포션 사용 확인으로 바꾸지 않는다. 회복·잔량·닫힘 중 하나라도 미확인이면 자동 재시도 없이 기존 resource_low 안전 종료로 돌린다. 현재 포션0개도 종료한다.

벨트 잔량을 기다리는 동안에도 같은 새 화면의 알려진 생명력50%/마나10% 미만은 잔량 승인보다 먼저 선점한다. 이를 resource_low_during_belt로 기록하며 추가 포션이나 잔량 추정 없이 종료 경로로 넘긴다. 마지막 펼침 관측이250ms 이내이면 그 관측으로 닫아 중복 촬영을 줄이고, 그렇지 않으면 기존 제한 안에서 새로 확인한다. 닫는 입력 전에도 포커스/중단·전체3초·화면250ms를 다시 검사한다. 실제 벨트 닫힘과 자원/HUD까지 포함한 복귀 허가는 별도 기록이다. 각 대기의 시한에 도달한 뒤 얻은 양성은 받아들이지 않는다.

비상 종료는 일반 마을 동작의 임의 대기 없이 기존 field backend를 사용한다. 현재 포커스/중단 확인 뒤 ESC 한 번, 최대8초 안의 현재 저장 종료 메뉴→실제 커서3px/50ms 정착→다음 새 메뉴 화면250ms→클릭 한 번으로 요청하고, 클릭 뒤20초 안의 새 캐릭터 선택 화면으로 완료를 확인한다. 목표 변화는 새 조준을 요구하며 미확인/오래된 화면·포커스 상실·중단·실제 커서 불일치에는 클릭하지 않는다. 반복 ESC/좌표 추측/사망 복구를 추가하지 않는다. 마지막 종료 관측 한 장과 ESC·조준·클릭·선택 관찰 시각을 실패에도 남긴다.

이동·목표 발판·대기 방어는 같은 consumer를 공유한다. 회복 중에는 경로/공격 입력을 보내지 않고 복귀 후 새 프레임으로 다시 판단한다. 입력 기록은 요청·회복 관찰·실제 벨트 수·닫힘을 구분하며 진단 이미지는 시도당 최대3장이다. 버프·경로 기억과 기존 시한을 임의 갱신하지 않는다.

전리품 검사와 ALT OFF 복원도 같은 consumer를 사용한다. 현재 저자원은 검사/버프 시한보다 먼저 처리하되 새 화면250ms·패널 없음·중단/포커스·포션 전제는 유지한다. 검사 한 회에서 최대1회만 회복을 시도하고 성공하면 이번 검사를 중단해 새 OFF 확인 뒤 현재 화면으로 돌아간다. OFF 복원에서 처음 회복했으면 새 안전 HUD로 복원을 마친다. 실패/같은 검사 중 재발은 resource_low로 main 안전 종료까지 전달하며 ALT 미확인/일반 경로 보류에 가리지 않는다. 현재 근접 위협의6초 방어 상한도 near_hostile_requires_review로 안전 종료에 전달한다. 추가 포션 재시도/무제한 전투/자동 사망 복구는 없다.

검사는 새 최대값의 같은 비율, 경계값, 오래된/미확인/잘못된 칸/중단/포커스 입력0회,1회 전송 뒤 회복/잔량/닫힘 미확인, 실제 잔량0, 성공 후 재관찰을 포함한다. 실게임 소비는 실제 낮은 비율과 전후 HUD·벨트·전송 기록으로 따로 확인한다.
