# 직업·스킬별 FCR과 텔레포트 참고 자료

- 조사일: `2026-10-05` (Asia/Seoul)
- 용도: [이동 PRD](../plans/prd/prd-0005-arcane-navigation-and-recovery.md#adaptive-teleport-requirements)의 공통화 계층과 시전 규칙 후보. 런타임 데이터 파일·현재 패치의 실행 검증·개별 캐릭터 FCR 측정은 아니다.
- 사용자 기준: 시전 규칙은 소서리스·팔라딘 등 직업별로 공통화한다. Flash 같은 개인 프로필은 해당 직업과 현재 장비의 FCR을 제공한다.

## 근거와 적용 범위

[Blizzard의 Caster Equipment](https://classic.battle.net/diablo2exp/classes/casterequipment.shtml)는 장비 FCR의 시전 속도 효과와 어쌔신 트랩의 예외를 안내한다. 아래 수치는 Blizzard가 직접 공개한 현재 D2R 표가 아니라 Librarian의 원 연구 자료 [Status Tables for all Classes](https://www.mannm.org/d2library/faqtoids/stattab_eng.html)의 Cast Rate 표를 요약한 것이다. [FCR 연구 설명](https://www.mannm.org/d2library/faqtoids/fcr_eng.html)은 직업·스킬 애니메이션·형상/장비 조건과 실제 효과가 발생하는 action frame을 구분한다.

원 연구 설명의 마지막 갱신 표시는 2006년이며, 과거 시전 지연 설명을 현재 D2R 규칙으로 복제하지 않는다. 자료를 읽은 날짜는 적용 패치의 검증 날짜가 아니다. 현재 기본 Resurrection 및 ROTW의 버전/직업/스킬/상태별 지원 범위는 실행 계약에서 따로 확인한다. 수치 조회에는 원문 출처·적용 조건·검증 상태를 함께 남긴다.

## 일반 시전 구간의 참고값

각 쌍은 **최소 FCR(%) → 애니메이션 프레임 수**다. 프레임은 캡처/렌더링 FPS의 프레임 개수가 아니다. 이 표는 원문의 일반 시전 애니메이션 요약이며 모든 직업/형상에서 텔레포트를 사용할 수 있다는 의미가 아니다.

| 직업 / 일반 상태 | 최소 FCR → 프레임 |
| --- | --- |
| 소서리스 / Sorceress | 0→13, 9→12, 20→11, 37→10, 63→9, 105→8, 200→7 |
| 바바리안 / Barbarian | 0→13, 9→12, 20→11, 37→10, 63→9, 105→8, 200→7 |
| 팔라딘 / Paladin | 0→15, 9→14, 18→13, 30→12, 48→11, 75→10, 125→9 |
| 네크로맨서 / Necromancer, 일반 형상 | 0→15, 9→14, 18→13, 30→12, 48→11, 75→10, 125→9 |
| 어쌔신 / Assassin | 0→16, 8→15, 16→14, 27→13, 42→12, 65→11, 102→10, 174→9 |
| 아마존 / Amazon | 0→19, 7→18, 14→17, 22→16, 32→15, 48→14, 68→13, 99→12, 152→11 |
| 드루이드 / Druid, 인간 일반 시전 | 0→18, 4→17, 10→16, 19→15, 30→14, 46→13, 68→12, 99→11, 163→10 |

근거: [Librarian의 직업별 Cast Rate 표](https://www.mannm.org/d2library/faqtoids/stattab_eng.html). 조회는 현재 FCR 이하에서 가장 높은 임계값을 선택한다. 예를 들어 일반 소서리스 시전은 FCR 63–104에서 9프레임, 105–199에서 8프레임이며, 팔라딘 일반 시전은 75–124에서 10프레임, 125 이상에서 9프레임인 구간이다. 같은 FCR 숫자를 직업 간에 같은 프레임으로 해석하지 않는다.

## 스킬·상태 예외

- 원 연구 표에서 소서리스 Lightning/Chain Lightning은 일반 시전과 별도다. 텔레포트에 그 표를 적용하지 않는다. 노바 빌드라는 이유로 텔레포트의 시전 계열을 바꾸지 않는다.
- 변신한 드루이드, Trang-Oul 뱀파이어 형상, 특수 스킬/애니메이션과 action frame 조건은 일반 표에서 분리한다. 위 일반 표에는 예외의 숫자를 합치지 않았다.
- FCR 표만으로 스킬 사용 가능 여부·고유 시전 지연·마나·아이템 부여 스킬/충전 잔량을 증명하지 않는다. 신규 직업·ROTW·모드의 규칙도 다른 직업 표로 대체하지 않는다.

## 프로젝트의 설계 해석

공통 규칙은 게임 계열/검증 버전·직업·스킬 시전 계열·관련 형상/애니메이션 조건으로 선택한다. 개인 프로필은 직업 참조, 활성 장비 세트의 확인된 총 FCR, 스킬/키와 개인 안전 설정을 제공한다. 장비 전환으로 FCR이 달라지면 조회와 세션 관측 보정의 유효성을 다시 확인한다. 이 소유 구분은 자료를 참고한 프로젝트 설계이며 게임 자료 자체의 지시가 아니다.

공통 표가 산출한 프레임은 초기 예상의 근거다. 화면에서 확인한 입력→도착 시간과 캡처/인식 지연은 별도 상태로 보정하고, 그 관측으로 원래 직업 표를 덮어쓰지 않는다. Flash는 사용자 확인상 소서리스이며 `2026-10-05` 현재 FCR 105를 확인했다. 다른 장비 세트별 FCR·실시간 활성 세트 확인은 미구현이다. 나머지 프로필의 직업은 이름이나 키로 추측하지 않는다.

[FEAT-0004](../plans/feature/feat-0004-class-casting-rules.md)가 후속 개발로 직업/FCR 로드와 입력 없는 공통 조회를 구현했다. [배포 reference 카탈로그](../../config/game-rules/casting.md)는 위 조사 중 소서리스·팔라딘 일반 텔레포트 두 표만 포함한다. 표 출처/revision/reference 상태를 결과에 남기며 현재 패치·실제 장비·이동 완료의 검증을 주장하지 않는다. 전체 직업의 실행 지원과 개별 런의 경로 검증은 각각 별도 증거가 필요하다.
